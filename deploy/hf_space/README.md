# Apex HiveStrike — 드론 엔지니어링 지식 서비스

Obsidian 지식 베이스 + GraphRAG + LangGraph 근거 검사로 드론 부품·소프트웨어·규제 질문에 출처를 붙여 답한다.

- `/` 사용자 화면 — 지식기반 답변, 분야별 둘러보기, 검색(키워드·벡터·키워드+벡터·GraphRAG 비교)
- `/admin` 관리자 화면 — 현황·수집함·위키 검토·예약 작업 (읽기 전용 스냅샷, 비밀번호)
